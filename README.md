# 📜 Stoic Quotes Generator

Este é um **Gerador de Frases Estoicas**, desenvolvido com **HTML, CSS e JavaScript**, utilizando a [Stoic Quotes API](https://stoic-quotes.com/) para obter frases inspiradoras dos grandes filósofos estoicos, como **Sêneca, Epicteto e Marco Aurélio**.

  
🔗 [Demonstração Online](https://pedro-rios66.github.io/STOIC-QUOTE-GENERATOR/) 

---

## 🎯 **Funcionalidades**
✅ Gera frases estoicas aleatórias com um clique.  
✅ Estilização inspirada na **Antiguidade Clássica**.  
✅ Interface responsiva e minimalista.  

---

## 🚀 **Demonstração**
Você pode testar o projeto diretamente pelo navegador no **GitHub Pages**:  
🔗 [https://pedro-rios66.github.io/STOIC-QUOTE-GENERATOR/](https://pedro-rios66.github.io/STOIC-QUOTE-GENERATOR/)  

Ou rodar localmente seguindo as instruções abaixo.

---

## 💻 **Tecnologias Utilizadas**
- **HTML5** → Estrutura da página  
- **CSS3** → Estilização inspirada na Antiguidade  
- **JavaScript (ES6+)** → Consumo da API e interatividade  
- **Stoic Quotes API** → Fonte das frases estoicas  
- **Google Fonts - Cinzel** → Tipografia inspirada na Roma Antiga  

---

## 🎨 **Tipografia**
Para reforçar a estética da **Antiguidade Clássica**, este projeto utiliza a fonte **Cinzel** do Google Fonts.

- 🏻 **Fonte Utilizada:** [Cinzel](https://fonts.google.com/specimen/Cinzel)  
- 🌟 **Licença:** SIL Open Font License (OFL)  
- 🔗 **Fonte importada de:**  
  ```css
  @import url('https://fonts.googleapis.com/css2?family=Cinzel:wght@400;700&display=swap');
  ```

A fonte **Cinzel** é inspirada na tipografia das inscrições romanas, trazendo um estilo clássico e imponente para o projeto.

## 📜 **Como Executar o Projeto Localmente**
1. **Clone este repositório**:
   ```sh
   git clone https://github.com/pedro-rios66/STOIC-QUOTE-GENERATOR.git
   ```
2. **Acesse a pasta do projeto**:
   ```sh
   cd stoic-quotes-generator
   ```
3. **Abra o arquivo `index.html` no navegador.**
